# Konkrét Matematika – interaktív tananyag

Egyetlen fájlból álló (`index.html`), vizuális, interaktív feldolgozás a *Konkrét matematika* (Graham–Knuth–Patashnik) fejezeteiről. A szövegek saját megfogalmazások, a könyv szövege nem szerepel benne.

## Elkészült modulok (1. fejezet: Rekurziós problémák)

- 1.1 Hanoi tornyai
- 1.2 Egyenesek a síkban
- 1.3 A Josephus-probléma

## Használat

Nyisd meg az `index.html`-t böngészőben. A képletek (MathJax 3) és a betűtípusok (Google Fonts) CDN-ről töltődnek be, ezért internetkapcsolat kell.

A `tools/` mappa az 1.2 és 1.3 modul forrásrészleteit tartalmazza (HTML-részek, JavaScript, router), az `index.html` ezek összefésült változata.

## Közzététel GitHub Pagesen

Settings → Pages → Deploy from a branch → `main` / `(root)`.
